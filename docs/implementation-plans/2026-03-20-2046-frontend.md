# Implementation Plan: Frontend

**Created:** 2026-03-20 **Type:** Feature **Overview:** A minimal React frontend for the video encoder — single-page utility UI where designers drop a video, watch encoding progress, and download the output files. **Design Spec:** docs/design-specs/2026-03-20-1803-frontend.md

---

## Summary

Scaffold a Vite + React + TypeScript client in `client/`, wire up ShadCN components, an SSE hook for encoding progress, and a single centered card UI that walks through upload → progress → download. Production build served as static files by Express.

**Code example:**

```ts
// api.ts
export async function uploadFile(file: File): Promise<{ jobId: string }> {
  const form = new FormData();
  form.append("file", file);
  form.append("presetId", "header-video");
  const res = await fetch("/api/encode", { method: "POST", body: form });
  if (!res.ok) {
    const body = await res.json();
    throw new Error(body.error ?? "Upload failed");
  }
  return res.json();
}

export function downloadUrl(jobId: string, codec: string): string {
  return `/api/encode/${jobId}/download/${codec}`;
}
```

**Done when:** ShadCN components are importable. `api.ts` exports `uploadFile` and `downloadUrl`.

## Acceptance Criteria

- [ ] User can drag-and-drop a video file onto the upload zone
- [ ] User can click the upload zone to browse for a file
- [ ] Files over 30MB show an inline validation error without uploading
- [ ] Non-video files show an inline validation error without uploading
- [ ] Upload triggers a POST to `/api/encode` and shows an indeterminate progress indicator
- [ ] After upload, a determinate progress bar reflects SSE encoding progress (0–100%)
- [ ] On encoding completion, two download buttons appear ("Download AV1", "Download H.264")
- [ ] Clicking a download button downloads the correctly named file
- [ ] Server errors display inline with a "Try again" button that resets to idle
- [ ] Lost SSE connection displays an error with "Try again"
- [ ] Vite dev proxy forwards `/api` requests to Express on port 3000
- [ ] `vite build` output is servable as static files by Express
